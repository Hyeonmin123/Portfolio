웹툰 정리 사이트

2026.10 – 현재개발중

여러 웹툰 플랫폼의 작품 약 1만 4천 건을 하나로 합쳐 보고 정리하는 개인용 사이트입니다. 이미 쓰고 있고, 필요한 기능을 계속 추가하고 있습니다.

AI를 활용해 제작했습니다. Claude Code와 대화하며 만들었습니다. 저는 무엇을 만들지 정하고, 결과를 확인해 틀린 부분을 바로잡았습니다.

만든 이유

웹툰 플랫폼마다 흩어져 있는 작품을 한곳에서 보고, 관심 있는 작품과 이미 본 작품을 직접 정리하려고 만들었습니다.

주요 기능

  • 관심 / 봤어요 / 숨기기 상태 관리
  • 본 날짜 기록과 회독 표시

  • 장르, 플랫폼, 정렬 필터
  • 성인 작품 분리

수집 기능은 개인 학습용 도구로 만들었습니다.
