웹툰 정리 사이트

2026.10 – 현재개발중

여러 웹툰 플랫폼의 작품을 한 화면에서 보고 정리하는 개인용 탐색 사이트입니다. 이미 쓰고 있고, 필요한 기능을 계속 추가하고 있습니다.

AI를 활용해 제작했습니다. Claude Code와 대화하며 만들었습니다. 저는 무엇을 만들지 정하고, 결과를 확인해 틀린 부분을 바로잡았습니다.

발견한 오류와 수정

만들면서 겪은 오류와 고친 방법입니다.

같은 작품이 제목만 다른 경우

문제
플랫폼마다 같은 작품의 제목 표기가 다릅니다.
해결
이름 정규화와 별칭 처리로 하나의 작품으로 묶었습니다.

회차 수가 권으로 표시되던 오류

문제
연재 회차 수(화)가 권으로 잘못 표시됐습니다.
해결
제가 결과를 보고 지적해 바로잡았고, 전자책 권 단위와 연재 화 단위를 섞지 않는 필터를 넣었습니다.

세트 상품이 가려지던 버그

문제
세트 상품이 목록에서 가려졌습니다.
원인
중복을 제거하는 순서에 문제가 있었습니다.
해결
버그를 수정했습니다.

직접 옮겨 적은 데이터의 오류

문제
직접 옮겨 적은 데이터에 틀린 줄이 있었습니다.
해결
해시로 검증해 틀린 줄을 찾아냈습니다.

정보가 부족한 작품

문제
일부 작품은 한 출처만으로는 정보가 부족했습니다.
해결
여러 출처의 정보를 모아 보강했습니다.

DB 손상

문제
중복 행과 인덱스 오류가 생겼습니다.
원인
갑작스러운 종료로 DB가 손상됐습니다.
해결
DB를 복구하고, 쓰기 내용이 디스크에 반영됐는지 확인하는 절차를 넣었습니다.

점검·차단 화면

문제
수집 중 점검이나 차단 화면이 뜰 수 있습니다.
해결
요청 속도를 제한하고, 이런 화면이 뜨면 우회하지 않고 멈춘 뒤 나중에 이어 받습니다.

검증하는 방법

  • 자동 테스트: pytest로 만든 테스트 67개가 통과합니다.
  • 데이터 검수: 직접 옮겨 적은 데이터를 해시로 검증해 틀린 줄을 찾아냅니다.
  • 화면 확인: 결과 화면을 직접 보고 틀린 표시(예: 화와 권)를 AI에게 지적해 고치게 합니다.
  • 저장 확인: 쓰기 뒤에 내용이 디스크에 반영됐는지 확인합니다.
  • 수집 중단 조건: 점검이나 차단 화면이 뜨면 우회하지 않고 멈춥니다.

만든 이유

웹툰 플랫폼마다 흩어져 있는 작품을 한곳에서 보고, 관심 있는 작품과 이미 본 작품을 직접 정리하려고 만들었습니다.

주요 기능

  • 관심 / 봤어요 / 숨기기 상태 관리
  • 본 날짜 기록과 회독 표시
  • 보기 싫은 장르 숨기기
  • 장르, 플랫폼, 정렬 필터
  • 성인 작품 분리

여러 웹툰 플랫폼의 작품 약 1만 4천 건을 하나로 통합해 보여줍니다.

수집 기능은 개인 학습용 도구로 만들었습니다. 요청 속도를 제한하고, 차단되면 멈춥니다.

구조

기술

  • Python
  • Flask
  • SQLite
  • 바닐라 JavaScript
  • pytest

프런트엔드는 프레임워크 없이 만들었습니다. 테스트 67개가 통과합니다.

로컬에서 서버를 띄워 쓰는 개인용 도구라 공개 링크는 없습니다. 수집한 데이터와 개인 기록은 공개하지 않습니다.
