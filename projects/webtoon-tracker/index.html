포트폴리오로 돌아가기

웹툰 정리 사이트

여러 웹툰 플랫폼의 작품을 한 화면에서 보고 정리하는 개인용 탐색 사이트입니다.

AI를 활용해 제작했습니다. Claude Code와 대화하며 만들었습니다. 저는 무엇을 만들지 정하고, 결과를 확인해 틀린 부분을 바로잡았습니다.

만든 이유

웹툰 플랫폼마다 흩어져 있는 작품을 한곳에서 보고, 관심 있는 작품과 이미 본 작품을 직접 정리하려고 만들었습니다.

주요 기능

  • 관심 / 봤어요 / 숨기기 상태 관리
  • 본 날짜 기록과 회독 표시
  • 보기 싫은 장르 숨기기
  • 장르, 플랫폼, 정렬 필터

네이버 웹툰, 카카오페이지, 리디와 기타 플랫폼 4곳의 작품 약 1만 4천 건을 하나로 통합해 보여줍니다.

기술

  • Python
  • Flask
  • SQLite
  • 바닐라 JavaScript
  • pytest

프런트엔드는 프레임워크 없이 만들었습니다. 구조는 플랫폼별 수집기(adapters), 가져오기 모듈(importers), DB 마이그레이션, 웹 API, 정적 프런트엔드로 나뉩니다. 테스트 67개가 통과합니다.

로컬에서 서버를 띄워 쓰는 개인용 도구라 공개 링크는 없습니다. 수집한 데이터와 개인 기록은 공개하지 않습니다.

어려웠던 점과 해결

같은 작품을 하나로 묶기

플랫폼마다 제목 표기가 달라서, 이름 정규화와 별칭 처리로 같은 작품을 묶었습니다. 정보가 부족한 작품은 여러 출처로 보강했습니다.

직접 옮긴 데이터 검수

직접 옮겨 적은 데이터를 해시로 검증해 틀린 줄을 찾아냈습니다.

화와 권을 섞지 않기

회차 수(화)가 권으로 잘못 표시되는 오류를 사용 중에 발견해 AI에게 알려 바로잡았습니다. 전자책 권 단위와 연재 화 단위를 섞지 않는 필터도 만들었습니다.

세트 상품이 가려지던 버그

중복을 제거하는 순서 때문에 세트 상품이 가려지는 문제가 있어 수정했습니다. 성인 작품은 따로 분리했습니다.

안정적으로 수집하기

수집은 속도를 제한하고, 점검이나 차단 화면이 뜨면 우회하지 않고 멈춘 뒤 이어 받습니다. 갑작스러운 종료로 DB가 손상됐을 때는 중복 행과 인덱스 오류를 복구했고, 이후 쓰기 뒤에 디스크 반영을 확인하는 절차를 넣었습니다.
